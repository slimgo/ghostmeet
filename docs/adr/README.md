# Решения

Указатель, чтобы не читать одиннадцать файлов ради одного. Здесь только «о чём
решение и живо ли оно»; основания — внутри.

**Заменённое остаётся в каталоге навсегда.** ADR в этом проекте не переписывается
и не удаляется: его ценность не в описании текущего положения дел, а в записи
того, **что было решено и на каком основании**. Заменить решение — значит выпустить
новый ADR со следующим номером и дописать в старый строку `status:`. Один раз так
уже терялся ADR-0005, восстановленный потом по памяти.

Поэтому колонка ниже важнее заголовка: **читать заменённый ADR ради текущего
устройства нельзя** — он расскажет, как было. Читать его стоит ради причины, по
которой прежнее решение казалось верным.

## Что читать под задачу

- **Звук, захват, протечка в `You`** → [0009](0009-no-vpio-echo-is-ours-to-handle.md), затем [0006](0006-screencapturekit-default-for-them.md). В 0009 перечислены и опровергнуты поимённо все очевидные обходные пути; переоткрывать вопрос, не прочитав его, — значит повторить измерения.
- **Когда и почему уходит запрос к модели** → [0008](0008-hotkey-triggered-suggestions.md).
- **Окно, скрытность, шаринг экрана** → [0004](0004-invisibility-scope.md) и [0011](0011-visibility-switch-in-the-window.md).
- **Новый бэкенд — провайдер, захват, распознавание** → [0001](0001-swappable-backends-behind-protocols.md), [0002](0002-stt-engine-choice.md).
- **Сеть без просьбы пользователя** → [0010](0010-update-check-at-launch.md): такой запрос в приложении ровно один, и добавлять второй — это новый ADR.
