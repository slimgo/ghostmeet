# Паки собеседований

Семь готовых интервью по специализациям — то, что отдают коллеге вместе с приложением. Каждый пак ведёт одно собеседование целиком: произносит вопрос голосом кусками с паузами, как говорит живой человек, и **ждёт**, пока кандидат ответит.

```bash
python3 .scratch/interview-packs/build.py
open .scratch/interview-packs/dist/index.html
```

Отдавать — `dist/interview-packs.zip`.

## Что внутри

| | |
|---|---|
| `template.html` | плеер: голоса, паузы, ход интервью, блок настроек |
| `strings/*.json` | подписи плеера по языкам — `ru` и `en` |
| `scripts/*.json` | сценарии, по одному на специализацию |
| `build.py` | подставляет сценарий в шаблон, раскладывает по папкам, пакует архив |
| `dist/` | результат сборки; в репозиторий не коммитится |

**Пак — одна самодостаточная страница, и это не из любви к простоте.** Паки открывают как файл, а браузер запрещает `file://` подтягивать соседние скрипты модулями. Разложенный на файлы пак у коллеги просто не запустится, и он решит, что сборка битая.

## Специализации

Бэкенд на Go · Фронтенд Vue/Nuxt · Фронтенд React · QA ручного тестирования · QA автоматизатор · CTO в стартап · Тимлид кросс-функциональной команды.

## Профиль и заготовки едут вместе с паком

Прямо на странице, над списком вопросов, напечатано то, что вписывают в настройки приложения: роль, опыт, стек и четыре поля «Контекста собеседования» — с кнопкой «Скопировать» у каждого.

Это часть стенда, а не удобство: у каждого пака примерно шестая часть вопросов помечена меткой **заготовка** и проверяет ровно это — придёт ли ответ из подготовленных историй или модель выдумает вилку зарплаты и чужой случай из практики.

## Языки

Пак знает свой язык: поле `language` в сценарии (`ru` по умолчанию). От него зависят
две вещи — подписи страницы, которые берутся из `strings/<язык>.json`, и **голоса**:
список фильтруется по языку пака, потому что английское интервью, прочитанное русским
голосом, не проверяет ничего.

Плеер при этом один на оба языка. Два его экземпляра разошлись бы на первой же
правке — ровно так, как расходятся два описания одного порядка, — поэтому языковое
вынесено наружу, а `template.html` остался один.

Английский сценарий — это **перевод** русского, а не новый сценарий: структура
(паузы, метки, второй голос, короткие хвосты) выверена прогонами и переносится
дословно. Меняются только слова, иначе пак проверял бы что-то другое.

Сейчас по-английски собран `go-backend-en`. Остальные шесть переводятся тем же
способом: `scripts/<slug>.json` → тексты → `scripts/<slug>-en.json`.

## Голоса

Их два: основной интервьюер и второй, который по сценарию подключается ближе к концу. В списке **только голоса языка пака**.

Первая версия показывала все голоса системы, русские отдельной группой сверху, — и это была ошибка: в списке оказалось сто восемьдесят строк, а второму интервьюеру достался китайский голос. Читать русский вопрос английским или китайским незачем ни при какой проверке.

Русский голос в macOS из коробки обычно один, и тогда второго интервьюера отличает тембр — иначе «нас сегодня двое» слышится как один человек, и второй голос в канале `Them`, ради которого он и заведён, не проверяется вовсе. В Chrome к системным добавляется свой «Google русский», так что там голосов два и тембр не нужен.

Доустановить: «Системные настройки» → «Универсальный доступ» → «Устная речь» → «Системный голос» → «Настроить»; там же живут улучшенные Милена и Юрий. Если русских не нашлось вовсе, страница показывает остальные и говорит об этом: пустой список хуже неподходящего.

## Паузы

Все паузы в сценариях **не длиннее секунды** — короче порога, по которому приложение закрывает реплику (1.5 с). Значит, вопрос доезжает в транскрипт одной записью. Так задумано: длинные разрывы на прогоне раздражали, а обратный случай проверяется ползунком «Паузы» — на 2× разрывы становятся длиннее порога, и вопрос приезжает двумя записями.

Потолок проверяет сборщик: сценарий с паузой больше секунды не соберётся.

## Метки у вопросов

Подсказка тестирующему, а не приказ:

| | |
|---|---|
| **отвечайте сами** | простой вопрос, приложение не трогайте |
| **⌥⌘A — коротко** | стоит попросить короткую подсказку |
| **⌥⌘Z — подробно** | тема, где нужен развёрнутый разбор |
| **заготовка** | ответ обязан прийти из «Контекста собеседования» |

## Как добавить свою специализацию

Положить `scripts/<slug>.json` той же формы и пересобрать. Форма: `slug`, `title`, `profile` (роль/опыт/стек), `context` (четыре поля заготовок), `entries` — список записей с `phase`, `kind` (`q` или `talk`), необязательными `hint`, `tail`, `who`, и `chunks` из пар «текст — пауза в миллисекундах».
