# 04 — Документы про два языка

**What to build:** документы тем же изменением, что и код.

**Что править:**

- [`CLAUDE.md`](../../../CLAUDE.md) — там сказано: «Both spec documents are written in
  Russian. Keep docs and in-app user-facing strings consistent with that». Вторая
  половина этой фразы после фичи неверна: строки интерфейса теперь двуязычны, а
  документы проекта — нет. Разделить явно, иначе следующий агент либо переведёт
  спеки, либо оставит новую строку по-русски;
- [`docs/GhostMeet.md`](../../../docs/GhostMeet.md) — структура файлов (каталог
  строк), список v1.0;
- [`CONTEXT.md`](../../../CONTEXT.md) — «язык интерфейса» и «язык разговора» это
  два разных понятия, и их путаница ровно та, ради которой писался тикет 03. Оба
  должны быть в глоссарии с явной разницей;
- [`README.md`](../../../README.md) и [`README.ru.md`](../../../README.ru.md) —
  приложение теперь говорит на двух языках, и англоязычный README это первое место,
  где об этом узнают;
- `CHANGELOG.md` — раздел версии.

**ADR — по результату тикета 03, а не по факту локализации.** Перевод интерфейса
решения не отменяет и ничего не пересматривает. А вот если правило скобок станет
условным — это правка авторитетного промпта, и её основание стоит записать там же,
где живут остальные решения о промптах, со ссылкой на прогоны.

**Отдельно: факт, стоивший времени, идёт в документы.** Неочевидное поведение
каталогов строк, момент применения языка, перезапуск — всё, что выяснилось
отладкой. Час, не оставивший следа в тексте, будет потрачен снова.

**Acceptance:**
- ни один документ не обещает, что интерфейс только русский;
- в глоссарии «язык интерфейса» и «язык разговора» различены явно;
- оба README говорят про два языка;
- ссылки ведут в существующие файлы;
- тикеты фичи со статусом `done` и комментарием о найденном.
