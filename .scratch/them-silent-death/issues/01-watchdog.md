# 01 — Сторож тихой смерти

**Status:** done

`SCKCaptureService` отмечает время каждого буфера **до** `makeFrame` — буфер,
который не удалось сконвертировать, всё равно доказывает, что поток жив, — и после
`.capturing` запускает задачу, которая раз в полпорога проверяет тишину. Пять
секунд без единого буфера — `recover(from: StreamWentSilent)`, тем же путём, что
обрыв с ошибкой: попытки, статус `.restarting`, в конце `.failed` и автооткат.

Проверяется двумя тестами на подставном потоке: замолчавший без ошибки поток
перезапускается; живой поток с пустыми буферами — нет. Паузы сторожа в тесте
отпускаются вручную, чтобы не ждать секунды; ожидание — по условию, а не по
`waitForRecovery`, который спрашивает раньше, чем сторож успевает ответить.

**Непроверено вживую.** Замер буферов на молчащем источнике — живой; сама тихая
смерть потока воспроизведена только подставным потоком. На следующем прогоне
владельца это единственное, чего нет в тестах.
